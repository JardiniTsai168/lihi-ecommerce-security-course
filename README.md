# lihi 電商資安小講座

「電商老闆必知的資安小講座」招生頁，以 lihi 品牌 DNA 全面重製，保留原始內容、講者資料、活動資訊與對外連結。

## Local preview

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Files

- `index.html` — page content and semantic structure
- `styles.css` — lihi visual system and responsive layouts
- `app.js` — navigation and reveal interactions
- `assets/` — official lihi logo and source speaker/partner imagery

## Deployment

Pushes to `main` deploy automatically through GitHub Pages.
